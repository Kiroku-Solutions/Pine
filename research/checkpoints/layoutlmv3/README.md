# Pine LayoutLMv3 research checkpoint

These files are the pair used for the Deliverable 2 demo and field-extraction experiment. Both are tracked with Git LFS.

| File | Role |
| --- | --- |
| `model.onnx` | LayoutLMv3 fine-tuned for Pine receipts, exported to ONNX and quantized to INT8 including embeddings (128.4 MB). |
| `tokenizer.json` | Matching tokenizer for the checkpoint. |
